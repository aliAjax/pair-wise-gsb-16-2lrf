# 职业听力监护台

噪声岗位员工的职业听力监护工作台：上岗基线、年度测听、30天复查与换岗结转，全流程本机保存。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 分层结构

监护资料、判定、本机保存、页面四层分离，互不依赖：

- `src/domain/types.ts` — 监护资料：员工、岗位噪声、测听记录（左右耳 2/3/4kHz 听阈）、换岗记录、复查任务
- `src/domain/rules.ts` — 判定规则（纯函数）：2/3/4kHz 平均听阈、对照基线的上移量、复查/干预结论、处理依据文本
- `src/storage/local.ts` — 本机保存层：localStorage 读写，与业务无关
- `src/state/store.tsx` — 状态编排：基线查找、唯一记录约束、复查任务开关、员工状态、换岗结转
- `src/ui/` — 页面：总览复查台、员工名册、员工监护档案
- `src/state/seed.ts` — 首次使用的演示数据（同样经判定层计算）

## 业务规则

1. 上岗先登记**基线测听**，作为以后对照基准。
2. **年度测听**对照基线：任一耳 2/3/4 kHz 平均听阈上移 ≥ 10 dB，自动建立 **30 天复查**任务。
3. **30 天复查**仍对照同一基线：上移仍 ≥ 10 dB 才列为**需干预**（脱离噪声、医学复查、按疑似职业性噪声聋流程上报）；回落则判定复查恢复、关闭任务。
4. **换岗**时未完成的复查任务随员工结转至新岗位，期限不重新起算；换岗记录保留前后岗位噪声、换岗前阈值与完整处理依据。
5. 同一员工同一天只允许一份有效测听记录（重复登记直接拒绝）。
6. 每份测听记录快照当时岗位与噪声，并保存完整处理依据（阈值、上移量、判定与处置意见）。

## 数据说明

全部资料仅保存在当前浏览器的 localStorage（键名 `hxwl-hearing-monitor-v1`），不上传服务器。页面右上角可清空并恢复演示数据。
