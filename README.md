# 职业听力监护台

面向噪声作业岗位的职业健康听力监护工作台：登记员工、岗位噪声与左右耳 2/3/4kHz 纯音听阈，
对照本人基线自动判定标准阈移（STS），跟踪 30 天复查并在复查仍上移时列为需干预；
换岗时未完成的复查随员工转到新岗位。判定依据 GBZ 188《职业健康监护技术规范》。

## 技术栈

React + Vite + TypeScript + CSS（纯前端，资料保存在本机浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- **监护看板**：接害员工数、待完成复查（含逾期）、需干预对象、7 日内到期复查；
  复查任务台（触发测听、期限、随岗转移、登记复查）与岗位噪声名册。
- **测听登记**：员工、测听时岗位（按日期自动带出）、日期、性质（基线/年度/30天复查）、
  左右耳 2、3、4kHz 听阈；实时计算 PTA 并预览对照前阈值的上移量与判定。
- **判定规则**：
  - 对照本人基线，任一耳 2/3/4kHz 平均听阈上移 ≥10dB → 安排 30 天复查；
  - 30 天复查仍上移 → 需干预；复查恢复 → 解除复查；
  - 未完成复查在换岗后随员工转到新岗位，期限不变。
- **员工 / 岗位 / 换岗**：岗位噪声（dB(A)、护听器）、员工登记上岗、换岗履历。
- **监护资料台账**：每条记录保留前阈值与本次阈值、处置与处理依据；
  同一员工同一天只留一份有效记录（旧记录标记作废可追溯）；支持编辑重新判定、删除。
- **员工监护档案**：测听历程、前后阈值对照、复查随转情况、上岗/换岗履历时间线。

## 分层结构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 监护资料 | `src/monitoring/types.ts` | 员工、岗位噪声、换岗履历、测听记录等数据模型 |
| 判定 | `src/monitoring/rules.ts` | 纯函数：PTA、STS 10dB、30 天复查、复查仍上移→干预、任务随换岗转移 |
| 本机保存 | `src/monitoring/storage.ts` | localStorage 整库读写、示例数据 |
| 操作编排 | `src/monitoring/service.ts` | 登记/保存/换岗等操作，调用判定层与保存层 |
| 页面 | `src/App.tsx`、`src/components/*` | 看板、表单、台账、档案等界面 |

判定层为纯函数、不依赖存储与 UI；保存层只管资料读写，便于以后替换为
IndexedDB 或后端 API，或对判定规则做单元测试。
